# Target 1900 学習アプリ

日本語話者向けの英単語学習Webアプリです。長期的な目標は、日常英会話とコンピュータ系の記事の概要理解です。現在は既存1900語を使います。

## 初期実装の使い方

1. 学習を開始し、英単語から日本語の意味を思い出します。時間制限はありません。
2. 「思い出せた」または「答えを見る」で意味を表示します。
3. 「思い出せた」「曖昧だった」「思い出せなかった・間違えた」で自己採点します。
4. 記録画面で回答履歴と復習予定を確認できます。
5. 記録画面のJSON・CSV出力でデータを取り出せます。読み込み・復元は未実装です。

回答速度だけで正誤は決めません。復習予定は自己採点と経過時間を中心に調整します。学習記録は同じブラウザー内に保存します。

## ファイル

- index.html：画面と操作。
- study-core.js：記録、復習計算、出力。
- data/target1900.js：既存1900語。内容と番号は元のアプリから変更していません。正確な書籍・サイトの出典と版は未確認です。
- docs/：方針、仕様、設計、実装指示書。
- tests/run.cjs：自動検証。依存パッケージは不要です。

## 起動

GitHub Pagesで main ブランチのルートを公開する場合、URLは https://hyodoarch.github.io/target1900-hyo/ です。PRの変更は main に取り込まれて公開処理が完了してから反映されます。

index.html、study-core.js、data/target1900.js を同じ構成で配信してください。

## 検証

Node.jsで次を実行します。

```sh
node tests/run.cjs
```

画面・保存・ダウンロードはモックで検証しています。Safari実機での音声とファイル保存は別途確認が必要です。
