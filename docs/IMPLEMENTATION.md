## 実装開始の条件

2026-10-01にユーザーから実装開始の指示を受けた。単語セットの選定は後回しとし、現在の1900語で初期実装を行う。今回採用する計測と復習の方式は DESIGN.md に記載する。

## 作業範囲と順序

1. 最新のコード、保存データ、出題・採点・復習処理を確認する。
2. 計測方法、復習計算、既存教材の分離とデータ移行を定め、設計書を更新する。
3. 3秒の強制終了と自動誤答を廃止する。
4. 利用者の操作で意味を表示し、3段階で自己採点できるようにする。
5. 回答履歴の保存と既存記録の移行を実装する。
6. 決定した方式で、本人と単語に合わせて復習予定を調整する。
7. JSON・CSVの出力操作を追加する。
8. 既存1900語を data/target1900.js に分離し、番号と教材内容を保持する。
9. 自動検証を実行し、変更をレビューできるPRにまとめる。
10. Safari実機と公開先での確認は、実施状況を明示する。

テキスト・Apple Pencil・音声回答、日本語から英単語を答える問題、端末間同期は今回実装しない。

復元、追加セットの選定と選択画面、イディオム教材の追加は後日検討する。

## 完了条件

| 対応要求 | 確認すること |
|---|---|
| R1 | 9秒を超えても問題が続き、自動で誤答にならない |
| R1 | 自己採点にかかった時間が回答時間に加算されない |
| R2 | 3段階を記録でき、未確定回答や連続操作で誤集計・重複保存しない |
| R3 | 時間だけで正誤が変わらず、曖昧な回答を別集計にできる |
| R4 | 確定した復習ルールに従い、日を空けた結果と直後の再出題を区別する |
| R5 | 既存記録を引き継ぎ、保存されていなかった履歴を作らない |
| R5 | 再読み込み後も確定済みの回答が残る |
| R6 | JSON・CSVをSafariから取り出せ、保存記録と内容が一致する |
| R6 | 出力しても学習記録が消えない |
| R7 | 既存1900語の抽出で英単語・意味・番号が変わらない |
| R7 | 教材の追加・編集が学習処理のコード変更を必要としない |
| R7 | 既存番号と記録の対応を保持する。セット切替機能は今回実装しない |
| R7 | GitHub Pagesで教材を読み込め、失敗時にも学習記録を保持する |
| R8 | 後日検討。今回の完了条件には含めない |

復習ルールとデータ移行は、固定した日時・履歴の例で検証する。

Safariで出題、自己採点、音声再生、データ出力を確認する。利用できない端末の確認を実施済みと報告しない。
